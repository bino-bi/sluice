# Contributing to sluice

sluice is in an early stage and the API is not final. The best contribution right now is an [issue](https://github.com/bino-bi/sluice/issues) or a [discussion](https://github.com/bino-bi/sluice/discussions) about a bug, a missing feature, or an idea.

Please do not open a pull request in advance. Open an issue or a discussion first and we talk about the next steps there. This may change once the project has a final API.

If we agree on a pull request:

- Run `make all` (fmt, vet, lint, test, build) before you open it.
- Your work is licensed under the project's existing terms: Apache-2.0 for `pkg/` and `sdk/`, AGPL-3.0-or-later elsewhere. New source files need the matching SPDX header.

## Security

Do not file security issues as public GitHub issues. See [SECURITY.md](SECURITY.md) for the coordinated disclosure process.
